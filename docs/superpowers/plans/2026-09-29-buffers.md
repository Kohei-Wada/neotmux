# Buffers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plugin writes lines into a buffer the host keeps and draws into a band or a float every frame, coloured by highlight groups the host holds, and `plugin.herdr.sidebar` rewrites its buffer only when an event changed something it shows.

**Architecture:** Two new stores in `neotmux-lua/src/draw/` — `TextBuffers` (buffers, lines, extmarks, namespaces, which window shows which buffer) and `HlGroups` — bound to Lua as `neotmux.buf.*` and `neotmux.hl.*`, with `set_buf` on the reserve and float handles. `LuaSubsystem::frame_output` projects every shown buffer into `DrawCmd`s against the window's rect of this frame; `Plugins::respond` recomputes the overlay on a quiet frame when a buffer or group changed. The server raises `pane_changed` (coalesced), `window_renamed` and three session events; the sidebar keeps a small model it updates from them and re-renders into its buffer only when it changed.

**Tech Stack:** Rust (mlua, Lua 5.4), the Lua runtime under `runtime/lua/`, cargo test, stylua, luacheck.

**Spec:** `docs/superpowers/specs/2026-09-29-buffers-design.md`

## Global Constraints

- One public type per file, named after it in `snake_case`; `mod.rs`/`lib.rs` hold only `//!` docs, `mod` and `use` lines (`docs/superpowers/specs/2026-09-25-layout-one-file-per-type-design.md` §1).
- Imports: std, then external, then crate, one `use` per module (`cargo +nightly fmt --all -- --config imports_granularity=Module,group_imports=StdExternalCrate` keeps it).
- herdr-derived logic stays in `runtime/lua/`; the crates only get neutral mechanisms.
- A malformed argument raises `mlua::Error::RuntimeError`; a legal call that loses returns `nil, message`.
- Buffer indexing is Neovim's: zero-based, `end` exclusive, `-1` is the end; `set_lines` is strict.
- Extmark `col`/`end_col` are columns as `neotmux_proto::screen::width::of_char` counts them.
- Highlight group names published by `neotmux.style` are `selector .. ':' .. part`.
- `make check` (fmt, stylua, luacheck, clippy `-D warnings`, `cargo test --workspace`) passes after every task.
- Work in a git worktree under `.worktrees/`; never touch the main checkout.
- Code, comments, docs and commit messages in English; commit subjects in the repo's style (a sentence saying what is now true, no `feat:` prefix), ending with the session's attribution lines.

## Review Focus

- A buffer shown in a window narrower than a line with a wide character straddling the edge → the character is left out, nothing is drawn past the window (Task 5 test `a_wide_character_at_the_windows_edge_is_left_out`).
- A band removed (`handle:remove()`) or a float removed while it still shows a buffer → nothing is drawn for it and nothing raises (Task 5 test `a_removed_window_shows_nothing`).
- A buffer changed during session A's dispatch while session B's frame is quiet → B's next frame shows the new lines without a tick running (Task 5 test in `neotmux-server/tests/headless.rs`, `a_quiet_frame_picks_up_a_changed_buffer`).
- `set_lines` replacing lines above an extmark → the extmark moves with its line; one on a replaced line is dropped (Task 4 test `replacing_lines_drops_their_extmarks_and_moves_the_ones_below`).
- A pane flooding output over many chunks in one frame → exactly one `pane_changed` for it (Task 2 test `pane_changed_fires_once_per_pane_per_frame`).

```rust
use crate::draw::Extmark;

/// One buffer: its lines and what colours them. A new one is one empty line, as Neovim's is.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TextBuffer {
    pub lines: Vec<String>,
    pub extmarks: Vec<Extmark>,
    pub next_extmark: u32,
}

impl Default for TextBuffer {
    fn default() -> Self {
        Self {
            lines: vec![String::new()],
            extmarks: Vec::new(),
            next_extmark: 1,
        }
    }
}

impl TextBuffer {
    /// Lines `start..end` become `lines`. An extmark on a replaced line is dropped — the one
    /// place this is not Neovim, where it would collapse to the start — and one below moves
    /// with its line. The caller has checked the range.
    pub fn set_lines(&mut self, start: usize, end: usize, lines: Vec<String>) {
        let added = lines.len();
        self.lines.splice(start..end, lines);
        let removed = end - start;
        self.extmarks.retain(|mark| mark.row < start || mark.row >= end);
        for mark in &mut self.extmarks {
            if mark.row >= end {
                mark.row = mark.row + added - removed;
            }
        }
        // Neovim keeps one empty line in a buffer with none.
        if self.lines.is_empty() {
            self.lines.push(String::new());
        }
    }
}
```

```rust
use std::cell::{Cell, RefCell};
use std::collections::BTreeMap;

use crate::draw::{BufId, BufWindow, TextBuffer};
use crate::plugin::SourceId;

/// Every buffer, who owns it, which window shows which, and the namespaces. The generation
/// moves on any change a frame would show.
#[derive(Default)]
pub struct TextBuffers {
    bufs: RefCell<BTreeMap<BufId, (SourceId, TextBuffer)>>,
    windows: RefCell<BTreeMap<BufWindow, BufId>>,
    namespaces: RefCell<BTreeMap<String, u32>>,
    next: Cell<u32>,
    generation: Cell<u64>,
}

impl TextBuffers {
    pub fn new() -> Self {
        Self::default()
    }

    fn bump(&self) {
        self.generation.set(self.generation.get() + 1);
    }

    pub fn create(&self, owner: SourceId) -> BufId {
        let id = BufId(self.next.get() + 1);
        self.next.set(id.0);
        self.bufs.borrow_mut().insert(id, (owner, TextBuffer::default()));
        id
    }

    pub fn exists(&self, id: BufId) -> bool {
        self.bufs.borrow().contains_key(&id)
    }

    pub fn delete(&self, id: BufId) {
        if self.bufs.borrow_mut().remove(&id).is_some() {
            self.windows.borrow_mut().retain(|_, shown| *shown != id);
            self.bump();
        }
    }

    pub fn with<R>(&self, id: BufId, f: impl FnOnce(&mut TextBuffer) -> R) -> Option<R> {
        let out = self.bufs.borrow_mut().get_mut(&id).map(|(_, buf)| f(buf));
        if out.is_some() {
            self.bump();
        }
        out
    }

    pub fn read<R>(&self, id: BufId, f: impl FnOnce(&TextBuffer) -> R) -> Option<R> {
        self.bufs.borrow().get(&id).map(|(_, buf)| f(buf))
    }

    pub fn namespace(&self, name: &str) -> u32 {
        let mut namespaces = self.namespaces.borrow_mut();
        let next = namespaces.len() as u32 + 1;
        *namespaces.entry(name.to_string()).or_insert(next)
    }

    pub fn show(&self, window: BufWindow, buf: Option<BufId>) {
        let mut windows = self.windows.borrow_mut();
        match buf {
            Some(buf) => windows.insert(window, buf),
            None => windows.remove(&window),
        };
        self.bump();
    }

    pub fn shown(&self) -> Vec<(BufWindow, BufId)> {
        self.windows.borrow().iter().map(|(w, b)| (*w, *b)).collect()
    }

    pub fn remove_all_of(&self, owner: SourceId) {
        let gone: Vec<BufId> = self
            .bufs
            .borrow()
            .iter()
            .filter(|(_, (o, _))| *o == owner)
            .map(|(id, _)| *id)
            .collect();
        for id in gone {
            self.delete(id);
        }
    }

    pub fn generation(&self) -> u64 {
        self.generation.get()
    }
}
```

```rust
//! lines the host keeps and draws in whatever window shows them.

use neotmux_proto::screen::width;

use crate::draw::{BufId, Extmark, TextBuffers};
use crate::plugin::{self, Groups, Held, Sources};

fn missing(buf: u32) -> mlua::Error {
    mlua::Error::RuntimeError(format!("buffer {buf} does not exist"))
}

/// Neovim's `start`/`end`: negative counts from past the end, so -1 is the end itself.
fn index(at: i64, len: usize, what: &str) -> mlua::Result<usize> {
    let resolved = if at < 0 { len as i64 + 1 + at } else { at };
    if resolved < 0 || resolved as usize > len {
        return Err(mlua::Error::RuntimeError(format!(
            "{what} {at} is out of range for a buffer of {len} lines"
        )));
    }
    Ok(resolved as usize)
}

fn lines_arg(lines: Table) -> mlua::Result<Vec<String>> {
    let mut out = Vec::new();
    for value in lines.sequence_values::<Value>() {
        match value? {
            Value::String(s) => {
                let s = s.to_str()?.to_string();
                if s.contains('\n') {
                    return Err(mlua::Error::RuntimeError(
                        "a line may not hold a newline; pass it as two lines".into(),
                    ));
                }
                out.push(s);
            }
            other => {
                return Err(mlua::Error::RuntimeError(format!(
                    "a line is a string, got {}",
                    other.type_name()
                )));
            }
        }
    }
    Ok(out)
}

pub(crate) fn install(
    lua: &Lua,
    sources: Rc<Sources>,
    bufs: Rc<TextBuffers>,
    groups: Rc<Groups>,
) -> mlua::Result<Table> {
    let t = lua.create_table()?;

    let create = {
        let bufs = bufs.clone();
        lua.create_function(move |lua, ()| {
            let owner = plugin::caller(lua, &sources);
            let id = bufs.create(owner);
            groups.note(Held::Buf(id));
            Ok(id.0)
        })?
    };
    t.set("create", create)?;

    let delete = {
        let bufs = bufs.clone();
        lua.create_function(move |_, buf: u32| {
            bufs.delete(BufId(buf));
            Ok(())
        })?
    };
    t.set("delete", delete)?;

                    })

            },
        )?
    };

                m.set("row", mark.row)?;

                m.set("end_col", mark.end_col)?;
                m.set("hl_group", mark.hl_group)?;
                m.set("line_hl_group", mark.line_hl_group)?;

            Ok(out)
        })?
```

```rust
use neotmux_proto::screen::width;
use neotmux_proto::{Color, DrawCmd, Rect};

use crate::draw::{HlGroups, TextBuffer};

#[derive(Clone, Copy, PartialEq, Eq)]
struct Cell {
    fg: Color,
    bg: Color,
    bold: bool,
}

/// `buf` drawn into `rect` (surface coordinates): line 0 at the top row, each line cut at the
/// rect's width with a wide character that would straddle the edge left out, a
/// `line_hl_group` as a `Rect` under its row, and the text as runs split where the colour
/// changes. Later extmarks win per channel.
pub fn project(buf: &TextBuffer, rect: Rect, hl: &HlGroups) -> Vec<DrawCmd> {
    let mut out = Vec::new();
    for (row, line) in buf.lines.iter().enumerate().take(rect.h as usize) {
        let y = rect.y + row as u16;
        let marks: Vec<_> = buf.extmarks.iter().filter(|m| m.row == row).collect();
        let mut base = Cell { fg: Color::Default, bg: Color::Default, bold: false };
        for mark in &marks {
            if let Some(group) = mark.line_hl_group.as_deref().and_then(|name| hl.get(name)) {
                // A group `neotmux.style` published is one colour, carried as `fg`: as a row's
                // group it is that row's background.
                if let Some(bg) = group.bg.or(group.fg) {
                    base.bg = bg;
                    out.push(DrawCmd::Rect {
                        pane: None,
                        rect: Rect::new(rect.x, y, rect.w, 1),
                        fg: Color::Default,
                        bg,
                    });
                }
            }
        }
        let mut col = 0usize;
        let mut run = String::new();
        let mut run_at = 0usize;
        let mut run_cell = base;
        for ch in line.chars() {
            let w = width::of_char(ch);
            if col + w > rect.w as usize {
                break;
            }
            let mut cell = base;
            for mark in &marks {
                let Some(name) = mark.hl_group.as_deref() else { continue };
                let end = mark.end_col.unwrap_or(usize::MAX);
                if col < mark.col || col >= end {
                    continue;
                }
                if let Some(group) = hl.get(name) {
                    if let Some(fg) = group.fg {
                        cell.fg = fg;
                    }
                    if let Some(bg) = group.bg {
                        cell.bg = bg;
                    }
                    if let Some(bold) = group.bold {
                        cell.bold = bold;
                    }
                }
                if let Some(bold) = mark.bold {
                    cell.bold = bold;
                }
            }
            if cell != run_cell && !run.is_empty() {
                out.push(text(rect.x + run_at as u16, y, std::mem::take(&mut run), run_cell));
            }
            if run.is_empty() {
                run_at = col;
                run_cell = cell;
            }
            run.push(ch);
            col += w;
        }
        if !run.is_empty() {
            out.push(text(rect.x + run_at as u16, y, run, run_cell));
        }
    }
    out
}

fn text(x: u16, y: u16, text: String, cell: Cell) -> DrawCmd {
    DrawCmd::Text { pane: None, x, y, text, fg: cell.fg, bg: cell.bg, bold: cell.bold }
}
```

```rust
    pub fn frame_output(&self) -> Vec<DrawCmd> {
        let mut bands = Vec::new();
        let mut floats: BTreeMap<FloatId, Vec<DrawCmd>> = BTreeMap::new();
        for (window, buf) in self.text_buffers.shown() {
            let rect = match window {
                BufWindow::Band(id) => self.reservations.owner(id).and_then(|o| self.reservations.band(o)),
                BufWindow::Float(id) => self.floats.rect(id),

            let Some(rect) = rect else { continue };
            let Some(cmds) = self.text_buffers.read(buf, |b| project(b, rect, &self.hl_groups)) else {

            match window {

                BufWindow::Float(id) => floats.entry(id).or_default().extend(cmds),
```

```lua
-- One row of the grid: its runs cut to `width` as `shrunk` cuts them, as a line of text and
-- the extmarks that colour it.
local function put(grid, y, x, width, runs)
  runs = shrunk(runs, width)
  local row = grid[y]
  for _, run in ipairs(runs) do
    local room = width - (row.cols - x)
    if room <= 0 then
      break
    end
    local text = run.text or ""
    if segments.columns(text) > room then
      text = segments.clip(text, room)
    end
    if text ~= "" then
      local at = row.cols
      row.text = row.text .. text
      row.cols = row.cols + segments.columns(text)
      if run.hl then
        row.marks[#row.marks + 1] = { col = at, end_col = row.cols, hl = run.hl, bold = run.bold }
      end
    end
  end
  if runs.fill then
    row.fill = runs.fill
  end
end

local function pad_to(row, col)
  if row.cols < col then
    row.text = row.text .. string.rep(" ", col - row.cols)
    row.cols = col
  end
end
```
